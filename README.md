# Python Practice & Programs

A collection of foundational Python scripts, exercises, and mini-games covering core programming concepts.

## 📁 Repository Contents

| File | Description |
|---|---|
| [`minigame.py`](minigame.py) | Interactive Number Guessing Game with random target and retry counter. |
| [`conditional.py`](conditional.py) | Conditional statements (`if`, `elif`, `else`), voting eligibility, temperature classification, and greeting logic. |
| [`loops.py`](loops.py) | Iteration examples, `for` loops, ranges, pattern generation, and series exercises. |
| [`while.py`](while.py) | `while` loops, digit extraction, number reversal, and palindrome checks. |
| [`operators.py`](operators.py) | Relational and logical operator demonstrations. |

---

## 🚀 Getting Started

Ensure you have Python installed on your system.

### Running a script
You can execute any script directly using Python:
```bash
python minigame.py
```
```bash
python conditional.py
```
